# Leaf-Home
Astro Blog

## 写作与本地预览

首页文章、连载作品与章节、独立散文均使用 Markdown。复制模板、草稿预览和发布说明见 [写作指南](WRITING.md)。运行 `pnpm preview:drafts` 后可在本地 4323 端口检查完整阅读流程。

## 文章浏览、筛选与站点图标

顶部保留“首页 / 文章 / 关于”。“文章”进入独立的 `/posts/` 年份时间线；文章标题进入正文，“返回文章”回到列表。原有创作页面仍可通过原地址访问，社交及链接入口暂不显示。

首页仅按发布时间倒序显示图文卡片，正文上方不放分类和标签筛选栏。桌面左栏放头像、分类、标签和音乐占位，右栏放碎碎念、统计、日历和近期状态；手机首页先展示文章，文章页则把分类与标签放在时间线前。

独立文章页左栏提供两级筛选：主分类“全部文章 / 技术 / 随笔”右侧显示文章总数，第二级显示当前分类的所有标签及各自篇数。“全部文章”下可选择所有标签；切换主分类会重置标签。筛选直接更新当前页时间线和年份计数。

当前条件写入 URL 的 `category`、`tag` 参数，刷新及浏览器前进、后退可恢复。点击“全部文章”或“清除筛选”重置条件。其他页面的左栏链接进入文章页并带上条件；禁用 JavaScript 时保留静态分类、标签归档。

## 达妮娅主题

界面已通过本地预览确认。布局参考 Firefly 的圆角卡片、左右侧栏和时间线，未引入其源码或素材。

- 亮色：奶白 / 浅粉 / 冰蓝，横幅使用用户提供的 `src/assets/hero-banner-light.png`。主句为“下次见面的时候，我会把挂在嘴边的讨厌全都替换成喜欢”，在逗号后断成两行，副句为“I want to tell the truth but I can't.”。
- 暗色：黑蓝 / 蓝紫 / 冰青，继续使用原 `src/assets/hero-banner.webp` 和“愿予你安然一梦”。
- 首页文案保留原色，直接浮在横幅上，不使用玻璃底。中英文同时开始，字符在同一个 3.2 秒窗口内依次像气泡一样弹出，停留后上浮淡出，约 16 秒一轮；亮色中文保留两行。字符动画在 `BubbleText.astro`，装饰气泡在 `Navbar.astro`，开启“减少动态效果”时显示静态完整文案。
- 配色在 `src/styles/tokens.styl`，横幅文字在 `src/config/site.ts`；文章仅在设置 `cover` 后显示封面，未设置时留白，手机端不保留空白封面高度。
- 导航、文章卡片、侧栏和阅读面板使用半透明毛玻璃，底层保留柔和的粉蓝 / 蓝紫色光晕，文字保持不透明；不支持背景模糊时使用原实色面板。
- 音乐只展示“暂无曲目”和禁用的播放控件，未连接播放服务。正文使用同套卡片与侧栏，有二、三级标题时生成目录锚点。

浏览器标签页图标使用 `src/assets/denia-pixel-head-v1.png`，由 Astro 生成 16px 和 32px 透明 PNG；导航 Logo 保持原黑兔。原图、角色参考及生成提示词说明见 [素材记录](src/assets/denia-pixel-head-v1.md)。

## 更新个人小组件

编辑 `src/config/personal.ts` 即可更新首页内容，修改后重新构建：

- `now`：最近在折腾。`updatedAt` 为更新时间，`items` 中的 `status` 可填 `ongoing`（进行中）、`done`（已完成）、`planned`（想做）。
- `notes`：碎碎念。每条填写 `date`（`YYYY-MM-DD`）和 `text`，首页按日期降序显示最近三条。
- `bookmarks`：保留原小书签数据配置，当前暂不展示书签组件及其导航入口。

碎碎念和近期状态在构建期生成。初始动态来自博客项目的实际进展，书签暂未填写。
